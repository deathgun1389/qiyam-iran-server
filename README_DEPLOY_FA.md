# راه‌اندازی موقت سرور قیام ایرانیان روی Render

این بسته برای استقرار سرور Node.js بازی روی Render آماده شده است. من از این محیط به حساب Render/GitHub شما دسترسی ندارم و نمی‌توانم به‌جای شما Deploy را نهایی کنم.

## مراحل
1. وارد GitHub شوید و یک مخزن جدید با نام `qiyam-temporary-server` بسازید.
2. فایل‌های همین بسته (`server.js`, `package.json`, `render.yaml`, `README_DEPLOY_FA.md`) را در ریشه مخزن آپلود/Commit کنید.
3. در Render وارد Dashboard شوید و `New +` → `Blueprint` را انتخاب کنید.
4. مخزن GitHub را متصل کنید و Blueprint را Deploy کنید.
5. پس از اتمام Deploy، آدرس شبیه `https://qiyam-temporary-server.onrender.com` به شما داده می‌شود.
6. سلامت را در مرورگر بررسی کنید: `https://YOUR-SERVICE.onrender.com/health`؛ پاسخ باید شامل `"ok":true` باشد.
7. در بازی آدرس WebSocket را به این شکل وارد کنید: `wss://YOUR-SERVICE.onrender.com` (بدون `/health`).

## محدودیت پلن رایگان
- سرویس‌های رایگان Render پس از مدتی بی‌فعالیتی می‌خوابند و اولین اتصال بعدی ممکن است زمان راه‌اندازی سرد بخواهد.
- دیسک دائمی در پلن رایگان در دسترس نیست؛ اطلاعات دنیا ممکن است با Restart/Deploy از بین برود. برای تست کوتاه‌مدت مناسب است، نه ذخیره دائمی جهان.
- برای یک ساعت روشن‌ماندن بدون تضمین خواب‌نرفتن، پلن پولی یا سرویس دیگری لازم می‌شود.

## نکته امنیتی
هیچ توکن/کلید محرمانه‌ای را داخل مخزن عمومی قرار ندهید.
